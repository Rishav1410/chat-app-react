# Chat App

A simple React + TypeScript app (built with Vite).

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Files

- `src/main.tsx` – starts React and renders `App`
- `src/App.tsx` – holds the display name and decides which screen to show
- `src/components/Login.tsx` – display name input + "Start chatting" button
- `src/components/Welcome.tsx` – shows "Welcome {name}"
